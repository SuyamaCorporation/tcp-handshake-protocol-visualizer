# TCP 三方向 ハンドシェイク 可視化

TCPの3ウェイハンドシェイク（SYN/SYN-ACK/ACK）と4ウェイFIN終了手順を矢印アニメーションで教育的に可視化するツール。

## 機能
- 接続確立（3-way handshake）と接続終了（4-way FIN）の2シナリオ
- クライアント/サーバーを左右に配置した矢印ダイアグラム
- 前へ/次へのステップバイステップ実行
- 自動再生（1.2秒間隔）・停止ボタン
- 各ステップのシーケンス番号・確認応答番号リアルタイム表示
- TCP状態遷移（CLOSED / SYN_SENT / ESTABLISHED / FIN_WAIT等）表示
- 各ステップの詳細説明文

## 技術
- Vanilla JS + Tailwind CSS CDN
- CSS / DOM ベースの矢印描画（Canvas不使用）
- ステップデータを配列で管理・インデックスベースのステップ制御
